# 📊 HR Analytics Dashboard | Power BI

## 📝 Project Overview
This is a small HR Analytics project I completed while learning HR Analytics through the NPTEL course.

As part of my learning, I built an interactive dashboard in Power BI to explore workforce data and practice presenting HR metrics through visualizations.

## 🔍 Analysis Covered
The dashboard explores:

1. 👥 Employee count by job role
2. ⚧️ Gender distribution of staff
3. 🎂 Age distribution of staff
4. 💰 Salary comparison across job roles
5. 🏆 Top earners within each job role
6. 🎓 Qualification versus salary
7. 📈 Employee growth trend over time
8. 🔤 Employee filtering by starting letter
9. 🌴 Leave balance analysis
10. 📌 HR dashboard overview
